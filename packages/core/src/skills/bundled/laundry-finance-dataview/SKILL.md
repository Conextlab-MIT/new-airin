# Laundry finance — Data View & Sheets

## Data View plugin

- When the org has the official **data-view** plugin enabled, use its tools/pages for synced tables.
- Summarize cash in/out, gross margin, and weekly trend from **visible rows only**.

## Google Sheets (Composio)

- Toolkit slug `googlesheets` when assigned and connected.
- Ask which spreadsheet/tab if multiple exist.

## Empty or partial data

- Ask the owner to type or confirm figures. Do not extrapolate missing months.

## Limits

- No inventory module, no tax filing advice — interpretation and flags only.
