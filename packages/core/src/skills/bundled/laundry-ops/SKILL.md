# Laundry operations

## SOPs

- Opening: power machines, cash float, WhatsApp greeting template.
- Closing: drain checks, bleach log, secure cash.
- Machine downtime: tag out, redirect express orders, owner SMS script.

## SLAs

- Standard 24h; express 4h when dryer line < 80% (user-configured).

## Automations

- Example only: Friday 16:00 inventory reminder via `create-automation` skill — do not create on stage unless the owner asks.

## Artifacts

- Export checklists as markdown artifacts when requested.
